## 사용된 기술
### 타일맵
- 맵 전체 크기만큼의 이미지가 아닌 한 칸의 자연스럽게 반복되는 이미지를 이용하여 맵을 그린다
- 맵을 전부 그리지 않고 화면에 보이는 것보다 조금 더 넓은 범위에만 타일을 생성하여 비용을 줄인다

### 제스처 라이브러리
- 특정한 이름의 제스처를 반복하여 그리고 플레이어가 제스처를 그리면 이미 등록되어있는 제스처들과 비교하여 일정 점수 이상이면 해당 제스처가 입력되었다고 판정한다.
- 제스처를 이용하여 공격 마법을 사용하는 방식으로 이용되었다.
