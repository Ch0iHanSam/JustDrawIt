# JustDrawIt
2026 4-1 스마트폰게임프로그래밍 프로젝트

## 게임 컨셉

- 그림을 그려서 마법을 사용하고, 마법을 이용하여 적들을 무찌르는 게임
- 핵심 메카닉 : 제스처 라이브러리를 이용해서 사용자의 제스처 인식하기
- 캐주얼, 핵 앤 슬래시(뱀서라이크)

## 개발 범위

- 오브젝트 충돌 체크
- 무한 맵 이동
- 제스처 라이브러리 구현

## 예상 게임 실행 흐름

## 개발 일정(8주)
- 1주차(4/6~4/12) : 캐릭터 이동 구현(방향키 기반)
- 2주차(4/13~4/19) : 무한 타일맵 구현
- 3주차(4/20~4/26) : 적 생성 구현(오브젝트 풀링)
- 4주차(4/27~5/3) : 공격 마법 2종 구현
- 5주차(5/4~4/10) : 공격 마법 2종 구현
- 6주차(5/11~5/17) : 제스처 라이브러리 구현
- 7주차(5/18~5/24) : 게임 시작, 옵션, 플레이, 종료 액티비티 연결 구현
- 8주차(5/25~5/31) : 보강, 버그 수정
