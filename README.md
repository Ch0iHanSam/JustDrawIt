## 액티비티 구성
- MainActivity: 게임의 유일한 입구이자 실행부
  -- BaseGameActivity를 상속받아 게임 엔진(a2dg 라이브러리)을 초기화
  -- MainScene을 생성하여 화면에 표시하고, 시스템 키 이벤트(뒤로가기 등) 및 터치 이벤트를 처리
  
## 씬 구성 및 관계
- MainScene (Scene 상속): 게임의 실제 플레이가 이루어지는 핵심 공간
  -- Layer 구조: 객체 간의 출력 순서를 관리
    --- BACKGROUND: 배경 타일
    --- PLAYER: 플레이어 캐릭터, 적(Enemy), 마법(Spell)
    --- HUD: 미니맵(Minimap), 테스트 도구(Test)
    --- World 관리: World 객체를 통해 각 레이어에 배치된 모든 오브젝트의 update와 draw를 통합 관리
  --상태 관리: 터치 시간에 따른 마법 발사 로직과 객체 간 충돌 감지(checkCollisions)를 직접 수행
  
## 오브젝트
1. 플레이어 (Player)
- 그림 구성: densis_illustration 리소스를 사용하며, Sprite 클래스를 통해 출력
- 동작 구성: WASD 키로 8방향 이동을 하며, 월드 맵(20x20 타일) 경계를 벗어나지 않도록 제한됩니다. 'C' 키 입력 시 무지개색으로 변하는 시각 효과
- 핵심 코드: 이동, 맵 경계 제한 이동
2. 적 (Enemy)
- 그림 구성: 플레이어와 같은 리소스를 사용하지만, PorterDuff 필터를 이용해 검은색 실루엣으로 표현
- 동작 구성: 플레이어 주변의 8개 가상 지점 중 하나를 목표로 삼아 지속적으로 추격
- 상호작용: 마법(Spell)과 충돌 시 제거되며, 즉시 맵의 랜덤한 위치에서 재생성
3. 마법 (MagicArrow & MagicSprinkle)
- MagicArrow: 하늘색 화살이며, 5개의 화려한 그라데이션 잔상이 남습니다.
- MagicSprinkle: 형광 초록색의 작은 알갱이 형태입니다.
- 동작 구성
  -- MagicArrow: 클릭 지점을 향해 직선으로 빠르게 날아갑니다.
  -- MagicSprinkle: 1초 차징 시 플레이어 정면 방향으로 부채꼴 형태로 30발을 연사합니다.
  -- 핵심 코드: interpolateColor(baseColor, targetColor, ratio), 터치 시간에 따른 마법 구분
4. 환경 및 UI (Background, Minimap, Test)
- Background: 20x20 크기의 타일 맵을 카메라 오프셋에 맞춰 무한히 반복 출력합니다.
- Minimap: 화면 우측 하단에 전체 맵 대비 플레이어(빨간 점)와 적(파란 점)의 위치를 실시간 비율로 표시합니다.
- Test: 개발용 도구로, 클릭 지점 효과 표시 및 객체들의 히트박스(빨간/파란 사각형)를 가시화합니다.

## 상호작용
- 충돌 판정: MainScene.update에서 매 프레임마다 RectF.intersects를 사용하여 마법과 적의 충돌을 검사합니다.
- 1:1 교환 시스템: 적이 죽으면 개체 수를 유지하기 위해 즉시 새로운 적이 화면 밖 랜덤 위치에서 생성됩니다.
- 카메라 시스템: 플레이어가 맵 중앙에 오도록 배경과 오브젝트의 좌표를 오프셋(offsetX, offsetY)으로 계산하여 상대적으로 그려줍니다.

## UX
1. 이동: 키보드의 W, A, S, D를 사용하여 캐릭터를 조작합니다.
2. 전투 (단발): 적이 있는 방향을 마우스로 짧게 클릭하면 유도 성능이 없는 강력한 화살(MagicArrow)이 발사됩니다.
3. 전투 (차징): 마우스 왼쪽 버튼을 1초 동안 꾹 누르고 있으면 캐릭터가 정면을 향해 형광 초록색 탄환(MagicSprinkle)을 대량으로 퍼붓습니다.
4. 관측: 우측 하단의 미니맵을 통해 보이지 않는 곳에 있는 적들의 위치를 파악하고 전략적으로 이동합니다.
